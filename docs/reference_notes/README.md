# Reference Notes

This directory stores natural-language notes extracted from reference projects.

Allowed content:

1. Product flows.
2. Behavior descriptions.
3. Module boundary observations.
4. Testing scenarios.
5. Interface ideas expressed without copied names or code.

Forbidden content:

1. Source code copied from reference projects.
2. Prompt text copied from reference projects.
3. Class names, function names, or file structure copied from reference
   projects.
4. Reference test cases copied or translated directly.
